# ww1-plans-reality-interactive
# 🌍 Підготовка країн до Першої світової війни: плани та реальність

Інтерактивний освітній вебпроєкт для учнів 9–10 класів із курсу всесвітньої історії. Дозволяє дослідити довоєнні плани ключових європейських держав (Німеччина, Франція, Велика Британія, Російська імперія, Австро-Угорщина та Італія) та порівняти їх із реальним перебігом подій у серпні-вересні 1914 року.

## 📌 Проєкт містить:
* **Інтерактивну схему-карту** взаємин і військових планів великих держав напередодні війни.
* **Картки країн із покроковими сценаріями** (від довоєнного планування до реальних бойових дій та політичних рішень).
* **Блок самоперевірки та роздумів** (тести з миттєвою перевіркою та проблемні запитання для обговорення).
